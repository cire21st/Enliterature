
# 📚 Enliterature (English Literature Reader)

> 2023년도 2학기 영문학 수업 강독 자료를 웹 환경에서 편리하게 읽고 탐색하기 위해 제작한 토이 프로젝트


## 📌 프로젝트 소개 (Overview)

수업 시간에 다루는 영문학 도서 및 텍스트 자료를 종이 문서나 PDF 대신, 
웹 브라우저에서 가독성 높고 편리하게 읽을 수 있도록 만든 개인용 웹 리더

* **수강 학기:** 2023-2
* **목적:** 영문학 강독 자료의 웹 텍스트화 및 편의성 제고


## ✨ 주요 기능 (Key Features)

* 📖 **웹 텍스트 뷰어:** 다양한 영문학 원문 텍스트를 깔끔한 UI로 읽기 가능
* 🔍 **목차 & 장(Chapter) 탐색:** 원하는 단원이나 섹션으로 빠르고 쉽게 이동
* 📱 **반응형 웹 UI:** 모바일, 태블릿, PC 등 다양한 디바이스 환경 지원

## 🚀 시작하기 (Getting Started)

### 로컬에서 실행하기

1. 저장소 클론
```bash
git clone https://github.com/cire21st/Enliterature.git
```
2. 프로젝트 폴더로 이동
```bash
cd Enliterature
```


3. `index.html` 파일을 브라우저로 열어 바로 확인 가능
